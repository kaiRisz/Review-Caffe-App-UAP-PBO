<h1>☕ APLIKASI REVIEW CAFE ☕</h1>

<h2>👋 Selamat Datang!</h2>

<p>
Aplikasi Review Caffe App merupakan aplikasi berbasis desktop yang dikembangkan
sebagai bagian dari Ujian Akhir Praktikum (UAP) mata kuliah
Pemrograman Berorientasi Objek (PBO). Aplikasi ini bertujuan untuk
memberikan sarana bagi pengguna dalam memberikan ulasan terhadap kafe,
serta membantu admin dalam mengelola data review secara terstruktur.
</p>

<p>
Aplikasi ini dibangun menggunakan bahasa pemrograman Java dengan
IDE NetBeans, menerapkan konsep Object-Oriented Programming (OOP).
Antarmuka pengguna dibuat menggunakan JavaFX dengan bantuan
Scene Builder, serta menggunakan PostgreSQL sebagai basis data.
Aplikasi ini memiliki dua role utama, yaitu Admin dan Pengguna.
</p>

<h2>⭐ Fitur Utama</h2>

<ul>
  <li>🔐 <b>Autentikasi Pengguna</b><br>
      Admin dan pengguna dapat melakukan login sesuai dengan peran masing-masing.</li>

  <li>🏪 <b>Manajemen Data Kafe (Admin)</b><br>
      Admin dapat menambahkan, mengubah, dan menghapus data kafe.</li>

  <li>📝 <b>Manajemen Review (Admin)</b><br>
      Admin dapat mengelola ulasan yang diberikan oleh pengguna.</li>

  <li>💬 <b>Pemberian Review oleh Pengguna</b><br>
      Pengguna dapat memberikan ulasan dan penilaian terhadap kafe.</li>

  <li>🎨 <b>Antarmuka Interaktif</b><br>
      Tampilan aplikasi dibuat menggunakan JavaFX agar mudah digunakan.</li>
</ul>

<h2>🛠️ Teknologi yang Digunakan</h2>
